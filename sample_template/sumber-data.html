6.1 Metode Ekstraksi

  1. Scraping HTTP: Python + requests + BeautifulSoup mengambil HTML setiap halaman
  2. Parsing Tabel: Tiga tabel (Influenza, COVID-19, RSV) di-parse per baris per kolom
  3. Ekstraksi Angka: Dari kolom Keterangan via regex — pola "menjadi X% dari Y%"
  4. Poin Utama: Regex "dari X pemeriksaan... terdapat Y kasus positif... positivity rate Z%"
  5. Penyimpanan: Excel (data_ringkasan_kasus.xlsx) → 4 sheet: Data_Lengkap, Rekap_Influenza, Rekap_COVID19, Rekap_RSV

6.2 Keterbatasan

  • Data hanya tersedia untuk 47 minggu: 2025 (M1 + M31-M53) dan 2026 (M1-M23)
  • 3 minggu (M28-M30/2025) tidak memiliki tabel — data dalam format narasi/prosa, belum diekstrak
  • CFR tidak dapat dihitung — tidak ada data kematian COVID-19 per minggu
  • Data provinsi per minggu tidak tersedia — hanya kumulatif tahunan
  • Perbandingan YoY terbatas — bukan full year, hanya minggu yang tumpang tindih
