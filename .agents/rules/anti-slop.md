# Anti-Slop & Quality Enforcement Rule

## Engineering Constraints
1. **Surgical Precision**: Only touch code directly relevant to the prompt. Do not reformat untouched functions.
2. **Preserve Code Structure**: Retain comments, documentation, and existing patterns.
3. **Verification First**: Always run tests or validation scripts before claiming completion.
4. **No Over-Engineering**: Do not introduce new libraries, frameworks, or layers without explicit requirement.

## Communication Guidelines
1. Be direct, factual, and concise.
2. Format answers with structured markdown and clickable links.
3. Answer in the same language as the user (Indonesian / English).
