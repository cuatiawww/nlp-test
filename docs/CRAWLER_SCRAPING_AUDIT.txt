CRAWLER / SCRAPING SYSTEM AUDIT
================================

Audit dilakukan secara read-only. Tidak ada source code, dependency, atau konfigurasi yang diubah.

1. CRAWLER YANG SUDAH ADA
--------------------------

Tool: WebScraperCollector
Lokasi file: services/collector-python/app/collectors/web_scraper.py
Fungsi: Mengambil HTML menggunakan requests dan Scrapling, mendeteksi halaman SPA/Cloudflare, kemudian melakukan parsing dengan BeautifulSoup, lxml, dan trafilatura.
Status: Aktif untuk collector_sources dengan source_type=web. Memiliki fallback HTTP dan browser stealth.

Tool: RSSNewsCollector
Lokasi file: services/collector-python/app/collectors/rss_news.py
Fungsi: Membaca RSS menggunakan feedparser, mengambil judul, ringkasan, URL, dan tanggal, lalu mengirim data ke RabbitMQ.
Status: Aktif dan digunakan oleh banyak sumber RSS.

Tool: CSVIngestCollector
Lokasi file: services/collector-python/app/collectors/csv_ingest.py
Fungsi: Mengambil CSV dari URL menggunakan requests, membaca baris CSV, menyimpan raw data, dan mengirimkannya ke RabbitMQ.
Status: Aktif.

Tool: SocialMediaCollector
Lokasi file: services/collector-python/app/collectors/social_media.py
Fungsi: Mengambil RSS media sosial dan mendukung Twitter API melalui Tweepy jika tersedia.
Status: RSS aktif. Twitter API belum aktif karena tweepy tidak tercantum di requirements.

Tool: Social CSV Watcher
Lokasi file: services/collector-python/app/collectors/social_csv_ingest.py
Fungsi: Memantau folder CSV media sosial, membaca post dan komentar, mengambil metadata OpenGraph, lalu mengirim data ke RabbitMQ.
Status: Aktif dan dijalankan scheduler setiap lima menit.

Tool: Manual Crawler
Lokasi file: services/worker-python/app/crawl_matrix_jobs.py
Fungsi: Mencari artikel melalui Google News RSS berdasarkan penyakit, negara, tanggal, dan keyword. Hasilnya dikirim ke endpoint ekstraksi URL dan NLP.
Status: Aktif sebagai worker terpisah secara proses, tetapi sumber pencariannya masih fokus pada Google News RSS atau URL langsung.

Tool: URL Analysis Worker
Lokasi file: services/worker-python/app/analysis_jobs.py
Fungsi: Mengambil URL langsung, menggunakan cache raw_reports jika URL pernah diproses, lalu mengirim artikel ke pipeline NLP.
Status: Aktif melalui queue disease.analysis-url.

Tool: SKDR API Collector
Lokasi file: services/collector-python/app/collectors/skdr_api.py
Fungsi: Mengambil data EBS/Alert melalui API, pagination, retry, exponential backoff, dan deduplikasi payload.
Status: Source code tersedia, tetapi mapping scheduler SKDR sedang dinonaktifkan sehingga tidak berjalan sebagai crawler aktif.

Tool: PDF Collector
Lokasi file: services/collector-python/app/collectors/pdf_document.py
Fungsi: Mengunduh PDF menggunakan requests dan membaca tabel/teks menggunakan pdfplumber.
Status: Aktif sebagai bagian dari URL Analysis.

Tool: Scheduler
Lokasi file: services/collector-python/app/scheduler.py
Fungsi: Menjalankan RSS, web, CSV, dan social collector berdasarkan konfigurasi collector_sources.
Status: Aktif menggunakan APScheduler.

4. KEKURANGAN
-------------

- Tidak ada sitemap crawling.
- Tidak ada recursive crawling atau link discovery.
- Tidak ada pagination umum untuk website HTML.
- Tidak ada rate limiter per domain.
- Tidak ada robots.txt handling.
- Tidak ada persistent cookie/session browser.
- Tidak ada generic exponential backoff untuk seluruh HTTP collector.
- Tidak ada CAPTCHA solver yang benar-benar aktif.
- Manual Crawler masih bergantung pada Google News RSS atau URL langsung.
- Manual Crawler belum menggunakan seluruh collector_sources sebagai sumber pencarian.
- Tidak ada content fingerprint deduplication global.
- CSV collector memakai built-in hash() untuk object key sehingga nilainya dapat berubah antar proses.
- Social CSV menggunakan checkpoint file, bukan deduplikasi database global.
- RSS feedparser tidak memiliki timeout HTTP eksplisit yang dikontrol oleh kode project.
- Twitter collector membutuhkan tweepy, tetapi package tersebut tidak tercantum pada requirements.
- Konfigurasi SOCIAL_CSV_BATCH_SIZE mengharapkan angka; nilai seperti all berpotensi menyebabkan error parsing.
- Exponential backoff SKDR tersedia tetapi collector SKDR sedang tidak aktif.
- Direct HTTP dan PDF fetch menggunakan verify=False sehingga validasi sertifikat TLS dinonaktifkan.
- Tidak ada OCR untuk PDF hasil scan.
- Tidak ada deduplikasi berbasis isi artikel jika URL berbeda tetapi kontennya sama.


5. REKOMENDASI
--------------

Sudah ada - tidak perlu ditambahkan:
- requests untuk HTTP dasar.
- feedparser untuk RSS/Atom.
- BeautifulSoup, lxml, dan trafilatura untuk parsing serta ekstraksi artikel.
- Scrapling untuk fetcher dan fallback halaman dynamic.
- APScheduler untuk crawler berkala.
- RabbitMQ untuk pemisahan pipeline raw, social, dan URL Analysis.
- Cache/deduplikasi URL pada raw_reports.
- pdfplumber untuk dokumen PDF.
- Retry dan pagination khusus SKDR API.
- Logging error dan status job.
- Worker terpisah untuk URL Analysis dan Manual Crawler.

Perlu konfigurasi - tidak perlu install:
- Atur timeout dan jumlah retry per jenis source.
- Atur interval crawler melalui collector_sources.
- Tambahkan konfigurasi delay per domain.
- Aktifkan dan konfigurasi source RSS/web yang memang dibutuhkan.
- Pastikan fetch_mode, selector artikel, proxy, dan wait_selector sesuai karakter website.
- Atur batas artikel, rentang tanggal, dan keyword Manual Crawler.
- Gunakan nilai numerik valid untuk SOCIAL_CSV_BATCH_SIZE.
- Konfigurasi validasi TLS secara konsisten.
- Atur CURRENT_YEAR_ONLY sesuai kebutuhan pencarian data historis.

Belum ada - kandidat penambahan:
- Sitemap crawler.
- Generic retry dengan exponential backoff untuk seluruh collector.
- Rate limiter per domain.
- Persistent cookie/browser profile.
- Content deduplication berbasis fingerprint.
- Recursive crawling dengan batas depth dan pagination.
- Integrasi Manual Crawler dengan seluruh collector_sources.
- OCR untuk PDF hasil scan.
- Integrasi Twitter API apabila memang diperlukan.
- Source-aware crawling untuk pencarian historis berdasarkan tahun atau bulan.
