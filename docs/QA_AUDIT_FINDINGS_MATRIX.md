# QA / Code Audit Findings Matrix

**Target:** [cuatiawww/nlp-test](https://github.com/cuatiawww/nlp-test) powering https://abvc-surveillance.org/nlp  
**Date:** 2026-09-15  
**Method:** Static review of Next.js, Rust API, NLP/collector/worker, plus live reads of production `/nlp/api/v1/*`. No exploit PoCs, attack scripts, or destructive calls were executed.

## Executive summary — top 5

1. **Unauthenticated admin and mutation APIs (Critical, Security).** `require_admin` exists but is only applied to interoperability writes and console settings PUT / audit logs. Production `GET /nlp/api/v1/users` returns admin accounts (usernames, roles, `permissions: ["*"]`). `create_user`, `delete_user`, `POST /api/v1/data/cleanup-events`, source CRUD, NLP dictionary writes, ingest, collect-all, and collector `upload-asset` have no server-side session check. UI `AuthGuard` is client-only.
2. **KPI totals are computed from `LIMIT 100` location/disease groups (High, DataMismatch).** Live `public-dashboard` returned exactly 100 `locations` and `kpis.deaths = 110,578`, while the unbounded trend query and `spatial-heatmap` report ~18.5–18.9 million deaths and ~3,154–3,375 events for the same year. Homepage cards use `kpis.*` for cases/deaths; `/nlp/tv` uses `trends.*.current`. The user’s hypothesis is confirmed: parallel endpoints do not share one filter/window/dedupe/limit contract.
3. **Implausible extracted counts dominate every aggregate (High, DataMismatch).** Production `/summary` top row is Ho Chi Minh City / Dengue **2,000,612,033** cases. Vietnam dashboard cases are ~2.00 billion. NLP `DEFAULT_CASE_COUNT=1` plus unrestricted `SUM(case_count)` (news totals, SKDR payloads, concatenated numbers) inflates “Detected Cases” far beyond epidemiological reality.
4. **Open CORS plus unauthenticated SSRF/upload surfaces (High, Security).** Live responses send `access-control-allow-origin: *`, `access-control-allow-methods: *`, `access-control-allow-headers: *`. `POST /api/v1/analyze-url` fetches arbitrary URLs; Next rewrites `/api/v1/console/upload` to collector `upload-asset` with no auth. Passwords are unsalted SHA-256; login has no lockout.
5. **Hardcoded week-36 cap, dummy SitRep/AI copy, and `/detail-region` template (High, DummyData / Bug).** Homepage default and EpiFilter reset use `endWeek: Math.min(current, 36)` (today is ISO week 38). `/nlp/reports` loads unfiltered `public-dashboard` (full year) plus 250 raw events. Generic AI summary is a canned paragraph. SitRep sanitizer injects seed stats (7,640 cases / 24 deaths). `/nlp/detail-region` still mounts a static `TEMPLATE_EVENT`.

## Hypothesis check

> Count mismatches may come from parallel endpoints using different filters/date windows or falling back to mock data in some environments.

**Verified.** The dominant numeric mismatch is **not** mock data on `/nlp` KPI cards (those cards do bind live JSON). It is:

1. `LIMIT 100` on the KPI/location query vs unbounded trend/heatmap SQL;
2. different validity rules (confidence, UNKNOWN, URL dedupe, `created_at` fallback, ASEAN-only vs OUTSIDE ASEAN);
3. different date windows (hardcoded epi week 1–36 vs full calendar year vs last 7 days);
4. extraction inflation (2.0B dengue) applied inconsistently when UNKNOWN/NEGATIVE rows are included (`/summary`, `/events/stats`).

Mock/seed data **does** leak on `/nlp/reports` SitRep sanitizer, canned `ai_summary`, and `/nlp/detail-region`.

## Out of scope / not exploited

- No calls were made to `cleanup-events`, `delete_user`, `create_user`, `ingest`, or `analyze-url` against production.
- Usernames and emails from `GET /users` are omitted from this document.
- Historical NLP accuracy bugs in `docs/BUG_FINDINGS_MATRIX.md` (location gazetteer, HFMD, ICD-11) were not re-validated end-to-end; several of those code paths still exist and can still bias counts (F-09, F-25).
